# Linux Environment Directory Setup

## Objective

Create a Linux directory hierarchy representing Development, Testing and Production environments.

## Platform

Utho Cloud Linux Server

## Command Used

mkdir -p company/project/{dev,test,prod}

## Structure

company/
└── project/
    ├── dev
    ├── test
    └── prod

## Outcome

- Practiced nested directory creation
- Simulated real deployment environments
- Improved Linux file management skills

## Real World Use Case

Software deployments are commonly separated into Dev, Test and Production environments.
