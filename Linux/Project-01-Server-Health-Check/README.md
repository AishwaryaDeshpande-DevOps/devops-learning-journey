# Linux Server Health Check

## Objective
Monitor basic Linux server health using native Linux commands.

## Platform
Utho Cloud Linux Server

## Commands Used

### Check Disk Usage
df -h

### Check Memory Usage
free -h

### List Files and Directories
ls

### Create Monitoring Directories
mkdir -p monitoring/logs/reports

## Outcome

- Monitored disk utilization
- Checked memory consumption
- Practiced Linux file navigation
- Created structured directories

## Real World Use Case

DevOps engineers frequently use these commands to troubleshoot infrastructure issues and monitor server health.
