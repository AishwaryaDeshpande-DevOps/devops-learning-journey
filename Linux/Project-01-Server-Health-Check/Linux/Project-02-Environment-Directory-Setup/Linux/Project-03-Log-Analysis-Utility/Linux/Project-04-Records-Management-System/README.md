# File-Based Records Management System

## Objective

Create and manage structured records using Linux files and command-line tools.

## Platform

Utho Cloud Linux Server

## Problem Statement

Many Linux-based systems store configurations, inventories, and operational data in text files. This project focuses on creating, editing, and validating structured records.

## Commands Used

### Create Project Directory

mkdir employee-records

### Navigate Into Directory

cd employee-records

### Create Records File

touch employees.txt

### Edit File

vim employees.txt

### Display Records

cat employees.txt

### Display First Records

head -n 2 employees.txt

### Display Last Records

tail -n 2 employees.txt

## Sample Records

## Outcome

- Created and maintained structured data files
- Edited records using Vim
- Retrieved information using Linux utilities
- Practiced file management operations

## Real World Use Case

Linux administrators and DevOps engineers frequently work with configuration files, deployment inventories, server lists, and operational records stored as text files.
